# Лабораторная работа №11

## Задание 3. Вариант 24 — «Автомобиль»

Создать структуру, заполнить её поля и вывести сведения об автомобиле, произведённом не позднее 2005 года и зарегистрированном в текущем году. Используется одна структура, без массива структур.

## Поля структуры

| Поле | Тип | Назначение |
| --- | --- | --- |
| `brand` | `char[100]` | Марка автомобиля |
| `manufacturer` | `char[100]` | Производитель |
| `type` | `char[100]` | Тип автомобиля |
| `year` | `int` | Год выпуска |
| `reg_day` | `int` | День регистрации |
| `reg_month` | `int` | Месяц регистрации |
| `reg_year` | `int` | Год регистрации |

## Алгоритм

1. Получить текущий год из системной даты с помощью `time()` и `localtime()`.
2. Ввести марку, производителя, тип и год выпуска автомобиля.
3. Ввести дату регистрации в формате `дд.мм.гггг`.
4. Проверить оба условия: год выпуска не больше 2005, год регистрации равен текущему году.
5. При выполнении обоих условий вывести все сведения об автомобиле.

Условие отбора в программе:

```c
if (a.year <= 2005 && a.reg_year == current_year)
```

Если хотя бы одно условие не выполняется, сведения об автомобиле после ввода не выводятся. Текущий год определяется при каждом выполнении программы.
